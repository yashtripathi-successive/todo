
# Project Safety Rules

1. Never read, edit, delete, or overwrite .env files.
2. Never expose credentials, tokens, or database passwords.
3. Never commit secrets or local environment files.
4. Never modify main or master directly.
5. Create a feature branch before implementation.
6. Follow approved specs and implementation plans.
7. Run testcase-writer before testcase-runner.
8. Commit and push only when all required tests pass.
9. Do not force push or automatically merge branches.
10. Stop and report any safety or verification failure.
